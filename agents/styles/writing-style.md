# 笔记写作风格

本文件定义笔记内容的写作风格。风格难以机械判定，但 Agent 应以此为原则编写和润色笔记内容。

本文件是一份持续迭代的"菜谱"，每次发现新的风格偏好时应更新。

## 角色与读者

- 角色：笔记作者的知识整理，面向未来的自己
- 读者：具有相关学科背景的人（包括未来的作者本人）
- 语气：教科书式的精炼陈述，不带个人情感、口语化修饰或感叹
- 整体结构：用多级列表表示思维导图，嵌套层级体现知识的分解关系

## 风格要点

### 加粗的使用

笔记的加粗承担结构功能，相当于思维导图中的节点标题。

**规则：加粗仅用于知识层级中的概念节点名称。**

不当 -> 正确：

- `**转发**（Forwarding）：路由器内的本地动作` -> `转发：路由器内的本地动作`（并列描述项不是概念节点，不加粗）
- `**缓解方法**：有限计数、水平分割` -> `缓解方法：` + 嵌套列表（分类标签不加粗）
- `这是一个**非常重要**的概念` -> `这是重要的概念`（不用加粗做强调）

正例（来自 `introduction.md`）：

```markdown
- **交换方式**
    - **电路交换**
        - 即 Circuit Switching。
```

`**交换方式**` 和 `**电路交换**` 是知识层级中的概念节点，加粗。下方的解释文字不加粗。

### 列表结构

**规则：拆为嵌套列表，不在一行内并列多个条目。有条目有解释时拆开写。**

不当 -> 正确：

- `LSP 包含：发送者标识、序列号（判断新旧）、年龄（每秒递减，归零丢弃）、直连邻居及链路代价。` -> 拆为嵌套列表，每个字段独占一行，解释紧跟其后

正确写法（来自 `network-layer.md`）：

```markdown
- LSP 包含：
    - 发送者标识：最初构造这个 LSP 的路由器。
    - 序列号：接收者用来判断新旧，只有更新的才可以被采用。
    - 年龄：每秒递减，归零丢弃。
    - 直连邻居及链路代价。
```

**规则：同类事物的枚举用"标签：描述"格式统领子项。**

正例（来自 `data-link-layer.md`）：

```markdown
- **分类**
    - 字符计数：每一帧的开头记录整个帧的长度。
    - 字节/字符填充：使用标志字节/字符划分边界，转义字符用于表示特殊字符本身。
    - 位填充：以 `01111110` 为边界，发送数据内容时遇到连续 5 个 `1` 就添加一个 `0` 强制区分。
```

### 精炼陈述

**规则：一行一个要点，解释具体到足以独立理解。**

不当 -> 正确：

- `缓解手段：有限计数（16 = 不可达）` -> `有限计数：限制距离上界，16 视为不可达。`（解释应具体，不省略关键细节）
- `毒性逆转：回传但距离设为无穷大。` -> `毒性逆转：向来源回传时，距离设为无穷大，其他目标不变。`（补全条件范围）
- `触发条件：拓扑变化、配置变化、定期刷新（约 30 分钟）。` -> 拆为三个独立列表项（一行一个要点）

**规则：不写引导性、总结性、强调性文字。**

不当 -> 正确：

- `接下来介绍距离向量算法。` -> 直接开始写距离向量的内容
- `综上所述，DV 和 LS 各有优劣。` -> 删除
- `值得注意的是，坏消息传播慢。` -> `坏消息传播慢。`

### 定义句式

- "……称为……"：`X` 称为 `Y`
- "……记作……"：`X` 记作 `Y`
- "……定义为……"：`X` 定义为 `Y`
- "如果……则……"：条件->结论
- "设……，则……"：引入假设->推导结果
- "已知……，则……"：引入前提->给出结论

### 数学与文字的关系

- 数学公式是陈述的一部分，不是独立展示块
- 先中文描述，紧跟公式。公式和中文是同一个句子的组成部分

不当 -> 正确：

- `$$d_x(y) = \min_v\{...\}$$` -> `基于 Bellman-Ford 方程：$d_x(y) = \min_v \{c(x, v) + d_v(y)\}$，$v$ 为 $x$ 的所有邻居。`（短公式用行内，先中文后公式）

- 短公式用行内 `$...$`，只有需要多行环境时才用 `$$...$$`
- 符号首次出现时用中文注明含义（如"信道负载 $G$：每毫秒内媒介上发送的帧数量"）
- 单位紧跟数值，用 `\mathrm{}` 排版
- 同一主题下的多个相关公式用逗号或句号分隔，不拆成独立列表项
- 极值或特殊条件的表述用"……时有……"句式，避免括号补充

正例（来自 `data-link-layer.md`）：

```markdown
- 吞吐率 $S = G e^{-2G}$，$G = 0.5$ 时有 $S_{\max} = \dfrac{1}{2e} \approx 0.184$。
```

### 连接词

- 极简：能用"同理"、"类似"、"推广到"四个字说清的，不用更多
- 常用连接词：同理、类似、推广到、反之、特别地、注意、即、则
- 不使用：然而、此外、与此同时、不仅如此、显而易见

正例（来自 `limit.md`）：

```markdown
- 同理还有 $x\to +\infty$ 和 $x\to -\infty$ 时的情况。
- 函数的情况同理。
```

### 推导和证明风格

- 不写完整证明过程，只记录关键步骤和结论
- 推论直接陈述结论，必要时在括号中注明推导来源
- 计算方法只记录核心步骤和关键公式，省略中间代数运算

### 术语处理

**规则：常见中文术语不附英文，仅在中文不常用或术语本身为缩写时附英文。**

不当 -> 正确：

- `网络层负责主机到主机（host-to-host）的分组交付` -> `网络层负责主机到主机的分组交付`（"主机到主机"是常见中文表达）
- `**转发**（Forwarding）` -> `转发`（"转发"是常见中文术语）
- `逐跳（hop-by-hop）` -> `逐跳`（同上）
- `距离向量（Distance Vector, DV）` -> `距离向量（DV）`（DV 是缩写，保留）
- `链路状态（Link State, LS）` -> `链路状态（LS）`（LS 是缩写，保留）
- `电路交换即 Circuit Switching` -> `即 Circuit Switching。`（无中文术语时附原文）

- 外国人名不翻译，直接使用原文
- 特定领域的惯例缩写直接使用，不每次展开（如 PCB、FCFS、SJF）

## 格式偏好

### 避免表格，使用列表

笔记内容和 Agent 文档中不使用 Markdown 表格。表格容纳内容少，格式控制复杂。使用嵌套列表替代。

### 偏好 ASCII 符号

使用 ASCII 符号而非 Unicode 符号。

- 不当 -> 正确：
    - `→` -> `->`
    - `≤` -> `<=`
    - `≥` -> `>=`

不当 -> 正确：

- 表格 `| 不当 | 正确 | 说明 |` -> 使用"不当 -> 正确："格式的列表项

## 禁止清单

- 废话开场白："本文将介绍"、"首先来看" -> 直接开始写内容
- 总结结尾："综上所述"、"总而言之" -> 删除
- 强调拐棍："值得注意的是"、"需要特别指出的是" -> 直接陈述事实
- 口语化表述：感叹号、反问句 -> 教科书式陈述
- 重复陈述：换种说法再说一遍 -> 删除重复
- 军事化/商业用语：深耕、赋能、闭环、抓手 -> 用准确的技术术语
- 三段式套话："首先……其次……最后……" -> 用列表结构
